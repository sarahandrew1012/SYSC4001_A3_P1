**Project Overview**

This project implements a system scheduler which consists of three algorithms: 
- Round robin,
- External Priority,
- A combination of round robin and external priority.

The program simulates the  interrupt process, as well displaying each algorithm output with the same data input.

**Organization of Project**

The program is excecuted with data contained inside the input files. The output of the program is written to the execution files which can be accessed in the output_files. 
```
├── input_files/        # Contains input for the schedulers
├── output_files/       #  Contains output for schedulers
└── bin                 # Contains bash for the schedulers
```
